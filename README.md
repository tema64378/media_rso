# Медиа конкурс РСО

Скелет проекта: Backend — Rust (Axum), Frontend — React + Vite (TypeScript), БД — MySQL.

Запуск (локально, пример):

1) Запустить БД:
   docker compose up -d

2) Backend (требует Rust и cargo):
   cd backend
   cargo run

3) Frontend (требует Node.js и npm/yarn):
   cd frontend
   npm install
   npm run dev

Дальнейшие шаги: добавить авторизацию, модели БД, загрузку файлов и API для оценок.
